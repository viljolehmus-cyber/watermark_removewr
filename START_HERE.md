# 🚀 START HERE - Run in 10 Seconds

## The Super Simple Way

### 1️⃣ **Install** (first time only)
```bash
pip install -r requirements.txt
```

### 2️⃣ **Run** (one command!)
```bash
python app.py
```

### 3️⃣ **Open Browser**
```
http://localhost:5000
```

**That's it! 🎉**

---

## What You'll See

A beautiful web app where you can:

1. **Upload** 📤 - Drag video onto page
2. **Select** 🎯 - Draw boxes around watermarks
3. **Configure** ⚙️ - Adjust protection zones
4. **Process** ▶️ - Click to remove watermarks
5. **Download** 💾 - Save cleaned video

All in your browser! No command line needed after startup.

---

## If Installation Fails

### On Linux/macOS:
```bash
pip3 install -r requirements.txt
python3 app.py
```

### On Windows:
```bash
python app.py
```

### If pip doesn't work:
```bash
python -m pip install -r requirements.txt
```

---

## Firewall/Access Issues

Can't see `localhost:5000`? Try one of these:

```
http://127.0.0.1:5000
http://localhost:5000/
```

Or check your browser's address bar and make sure it matches.
